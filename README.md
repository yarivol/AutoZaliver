# AutoZaliver — инструкция для начинающего

Программа берет готовое видео из папки `to_upload` и по очереди пытается опубликовать его в YouTube, Instagram и TikTok. После обработки переносит файлы в `done` и ждет два часа перед следующим роликом.

**Первую настройку нужно выполнить один раз. После этого обычная работа — положить видео с описанием в папку, открыть программу и нажать «Старт».**

## 1. Где находится программа

Ваша папка программы:

```text
C:\Users\Yarivol\Desktop\AutoZaliver
```

Главный файл — `autozaliver.py`. Этот документ — `README.md`; его можно открыть Блокнотом.

## 2. Установка

Для следующих команд используйте PowerShell. Откройте папку программы в Проводнике, в адресной строке сверху введите `powershell` и нажмите Enter. Появится окно для ввода команд.

Копируйте команды ниже по одной, нажимайте Enter и ждите завершения. Значки оформления блока копировать не нужно.

Проверьте Python:

```powershell
python --version
```

Программа рассчитана на Python 3.11 и новее. Если команда не работает, установите Python с [официального сайта](https://www.python.org/downloads/windows/). В установщике с такой опцией отметьте `Add python.exe to PATH`. После установки закройте и заново откройте PowerShell.

Перейдите в папку программы:

```powershell
Set-Location "C:\Users\Yarivol\Desktop\AutoZaliver"
```

Создайте отдельное окружение для библиотек программы:

```powershell
python -m venv .venv
```

Установите библиотеки. Загрузка может занять несколько минут:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
```

```powershell
.\.venv\Scripts\python.exe -m pip install customtkinter watchdog google-api-python-client google-auth-oauthlib instagrapi tiktokautouploader
```

Для TikTok установите также Node.js с [официального сайта](https://nodejs.org/), затем заново откройте PowerShell в папке программы. Проверьте команды:

```powershell
node --version
```

```powershell
npm.cmd --version
```

Установите браузер, который использует загрузчик TikTok:

```powershell
.\.venv\Scripts\phantomwright_driver.exe install chromium
```

Node.js, npm и установка Chromium указаны в [инструкции автора загрузчика TikTok](https://github.com/haziq-exe/TikTokAutoUploader#pre-requisites). Если установка завершилась ошибкой, сначала исправьте ее: открывшееся окно AutoZaliver само по себе не означает, что все загрузчики установлены.

## 3. Настройки программы

Закройте AutoZaliver перед изменением настроек. Откройте `autozaliver.py` через «Открыть с помощью → Блокнот» или редактор кода. В начале файла найдите блок `CONFIG = {`.

Меняйте значения справа от двоеточия. Сохраняйте кавычки, запятые и скобки. После редактирования нажмите Ctrl+S. Настройки применятся после нового запуска приложения.

### Instagram

Найдите эти строки и впишите свои данные:

```python
    "ig_username": "YOUR_INSTAGRAM_LOGIN",
    "ig_password": "YOUR_INSTAGRAM_PASSWORD",
    "ig_proxy": "",
```

- `ig_username` — логин Instagram без символа `@`.
- `ig_password` — пароль Instagram.
- `ig_proxy` — адрес вашего мобильного прокси с логином и паролем **прокси**, а не Instagram.

Формат прокси:

```text
http://ЛОГИН_ПРОКСИ:ПАРОЛЬ_ПРОКСИ@IP_АДРЕС:ПОРТ
```

У провайдера должны быть получены четыре значения: логин, пароль, IPv4-адрес и порт. В этой версии адрес должен состоять из цифр и точек; доменное имя вместо IPv4 не принимается. Программа не создает мобильный прокси и не может проверить, действительно ли подключение мобильное.

Чтобы подключаться к Instagram напрямую, без прокси, оставьте настройку пустой:

```python
"ig_proxy": "",
```

Если в логине или пароле прокси есть `@`, `:`, `/`, `#` или `%`, запросите у провайдера готовый URL с корректным кодированием этих символов.

После успешного входа программа создаст `session.json` и будет использовать сохраненную сессию при следующих запусках. В интерфейсе нет отдельного поля для кода двухфакторной аутентификации или проверки Instagram: если потребуется дополнительное подтверждение, вход может завершиться ошибкой. Проверьте аккаунт через обычное приложение Instagram и сообщение в журнале.

Если пароль внутри Python-строки содержит двойную кавычку, записывайте ее как `\"`, а обратную косую черту — как `\\`.

### TikTok

Найдите:

```python
    "tiktok_profile": "my_tiktok_account",
```

Вместо `my_tiktok_account` укажите постоянное имя локального профиля, например `my_channel`. Это имя передается загрузчику для сохранения данных входа; пароль TikTok в CONFIG не вводится.

При первом обращении к TikTok выполните вход в окне, которое откроет загрузчик. Используйте нужный аккаунт. Не меняйте имя профиля после каждого запуска: иначе библиотека может запросить вход заново. Первый запуск может быть долгим из-за подготовки компонентов. Такое поведение описано в [документации загрузчика](https://github.com/haziq-exe/TikTokAutoUploader#quick-start).

### YouTube

Для YouTube нужен файл доступа, скачанный из вашего проекта Google Cloud. Это не пароль от аккаунта и не обычный API key.

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и войдите в Google-аккаунт.
2. Создайте или выберите проект.
3. В библиотеке API найдите **YouTube Data API v3** и включите его.
4. Если консоль просит настроить экран согласия OAuth / Google Auth Platform, заполните название приложения и контактный адрес. При режиме Testing добавьте свой Google-аккаунт в тестовые пользователи.
5. Создайте учетные данные **OAuth client ID**, тип приложения — **Desktop app / Приложение для компьютера**. Названия разделов консоли могут отличаться.
6. Скачайте JSON с учетными данными.
7. Переименуйте скачанный файл в `client_secrets.json` и положите рядом с `autozaliver.py`.

Основа настройки проекта и Desktop OAuth приведена в [инструкции Google](https://developers.google.com/youtube/v3/quickstart/python#step_1_set_up_your_project_and_credentials).

При первой попытке загрузки откроется браузер. Выберите аккаунт нужного YouTube-канала и разрешите загрузку видео. В текущих настройках на первичный вход отведено 180 секунд. Программа сама сохранит `token.json` — создавать его вручную не нужно.

Настройка видимости:

```python
    "youtube_privacy": "public",
```

Возможные значения: `public` — публичное видео, `unlisted` — доступ по ссылке, `private` — личное. Эта настройка относится **только к YouTube**; тестовый запуск продолжит загрузки в Instagram и TikTok.

У непроверенных API-проектов Google может ограничивать загрузки личным доступом даже при `public`. Это ограничение описано в [документации videos.insert](https://developers.google.com/youtube/v3/docs/videos/insert).

`youtube_made_for_kids` задает признак «для детей»: `True` — да, `False` — нет. Укажите значение, соответствующее вашему ролику.

### Тексты по умолчанию

```python
    "default_title": "Новое видео #Shorts",
    "default_description": "Новое видео! #shorts #reels #tiktok",
```

Эти тексты используются, когда рядом с роликом нет TXT. Остальные настройки для обычного использования менять не нужно. Пути `to_upload` и `done` отсчитываются от папки программы.

## 4. Как подготовить видео и описание

Программа принимает готовые файлы `.mp4`. Она не монтирует видео, не делает его вертикальным и не проверяет соответствие требованиям каждой площадки. Подготовьте вертикальный ролик заранее.

В папке `to_upload` должны лежать два файла с одинаковым основным именем:

```text
video_001.mp4
video_001.txt
```

Пример содержимого `video_001.txt`:

```text
Первая строка может быть оставлена для совместимости, но заголовок берется из имени MP4.
Показываю мой любимый рецепт кофе.
Сохраните, чтобы попробовать!
#кофе #рецепт #shorts
```

Название видео берется из имени MP4 без расширения. Например, файл `Как_готовить_кофе.mp4` получает заголовок `Как_готовить_кофе` на YouTube. Для Instagram и TikTok это название добавляется первой строкой подписи. Все строки TXT после первой добавляются к описанию. Если TXT отсутствует или содержит только первую строку, используется `default_description` из CONFIG.

Как создать TXT в Блокноте:

1. Откройте Блокнот и напишите заголовок и описание по примеру.
2. Нажмите «Файл → Сохранить как».
3. Выберите папку `to_upload`.
4. Укажите имя `video_001.txt`, тип «Все файлы», кодировку **UTF-8**.
5. В Проводнике включите отображение расширений файлов и убедитесь, что имя не получилось `video_001.txt.txt`.

Сначала положите TXT, затем готовый MP4. Можно готовить оба файла вне `to_upload` и переносить их после сохранения. Во время обработки не переименовывайте и не редактируйте их.

Если TXT отсутствует, используются оба текста из CONFIG. Если TXT содержит только заголовок, описание будет пустым. Пустая первая строка заменяется заголовком по умолчанию.

Файлы во вложенных папках не обрабатываются. Ролики выбираются по имени; для понятного порядка используйте `video_001.mp4`, `video_002.mp4`, `video_003.mp4`.

## 5. Первый запуск

1. Убедитесь, что установка завершена, CONFIG заполнен, а `client_secrets.json` лежит рядом с программой.
2. Подготовьте один ролик и его TXT, которые действительно хотите опубликовать. Отдельного режима «проверка без публикации» нет.
3. Откройте PowerShell в папке программы.
4. Выполните:

```powershell
.\.venv\Scripts\python.exe autozaliver.py
```

5. В открывшемся окне нажмите **«Старт»**.
6. Выполните первичный вход в браузере, когда его запросит YouTube или TikTok.
7. Читайте сообщения в нижней части окна и после завершения проверьте ролик на каждой площадке.

Папки `to_upload` и `done` создаются при нажатии «Старт», если их еще нет. Их также можно заранее создать вручную.

## 6. Обычная работа после настройки

1. Откройте PowerShell в папке программы.
2. Запустите `.\.venv\Scripts\python.exe autozaliver.py`.
3. Положите TXT и MP4 в `to_upload`.
4. Нажмите «Старт» и оставьте программу работать.

Видео можно добавлять и во время работы. Уже лежащие в папке ролики тоже будут найдены. Запускайте только одно окно AutoZaliver: защиты от двух одновременно работающих экземпляров в этой версии нет.

Компьютер должен оставаться включенным, с интернетом и без перехода в сон. После закрытия программы публикации не продолжаются в фоне.

## 7. Что означают кнопки и сообщения

| Элемент | Что означает |
| --- | --- |
| «Старт» | Начать или продолжить обработку очереди. |
| «Стоп» | Прервать ожидание и остановиться перед следующей загрузкой. Уже начатый вызов загрузчика должен завершиться. |
| «В очереди» | Количество MP4 в `to_upload`, включая текущий ролик до его переноса в архив. |
| «Жду файлы» | Программа работает, но свободных роликов для обработки нет. |
| «Жду завершения записи файла» | Проверяется, перестал ли файл изменяться; ожидание не меньше 15 секунд. |
| «Загрузка в …» | Сейчас выполняется вход или публикация на указанной площадке. |
| «Пауза 20 секунд» | Ожидание между площадками. |
| «Сон 2 часа» | Текущий цикл завершен, следующий ролик пока не берется. |
| «Конвейер остановлен» в журнале | Прочитайте причину ошибки, исправьте ее и нажмите «Старт» после завершения остановки. |

Обычный порядок: ожидание готовности файла → YouTube → 20 секунд → Instagram → 20 секунд → TikTok → перенос файлов → 7200 секунд ожидания.

Ошибка одной площадки не мешает попыткам на следующих. **Даже если все три попытки закончились ошибками, файлы переносятся в `done`, и начинается двухчасовая пауза.**

При закрытии окна программа тоже сначала ожидает завершения текущего вызова загрузчика. Ожидание сетевого ответа или входа может занять время.

## 8. Где искать файлы и результаты

```text
AutoZaliver/
  autozaliver.py          программа и настройки CONFIG
  README.md              эта инструкция
  .venv/                 установленные библиотеки
  client_secrets.json    скачанные учетные данные YouTube
  token.json             сохраненный вход YouTube
  session.json           сохраненный вход Instagram
  pipeline_state.json    прогресс обработки и время следующего ролика
  to_upload/             очередь видео
  done/                  обработанные видео и описания
```

В `done` для каждого ролика создается отдельная папка, например `video_001_a1b2c3d4e5f6`, куда попадают его MP4 и TXT. Загрузчик TikTok также может создавать свои файлы профиля в рабочей папке.

**`done` означает «попытки обработки завершены», а не «успешно опубликовано везде».** Проверяйте сообщения «Ошибка …», итог цикла и сами аккаунты. Сообщение TikTok о завершении функции не является независимой проверкой наличия публикации.

Журнал показывается в окне, автоматически в файл не сохраняется. При необходимости выделите и скопируйте нужный текст до закрытия окна. Старые строки постепенно удаляются из длинного журнала.

Не передавайте другим людям CONFIG с паролями, файлы сессий, токены и данные профиля TikTok: они содержат данные доступа к аккаунтам.

## 9. Остановка, перезапуск и повторная публикация

Программа сохраняет, какие площадки уже пыталась обработать. После остановки и нового запуска она продолжает оставшиеся этапы. Завершенные попытки, в том числе ошибочные, автоматически не повторяются.

Если программа аварийно закрылась прямо во время загрузки, результат этой попытки может быть записан как «исход неизвестен». При следующем запуске такая площадка пропускается. Сначала проверьте аккаунт: ролик мог успеть опубликоваться.

Двухчасовой таймер сохраняется в `pipeline_state.json`. Закрытие окна или нажатие «Стоп», а затем «Старт» не сбрасывают его. Если время уже прошло, обработка продолжится после запуска.

Не удаляйте `pipeline_state.json` для устранения обычной ошибки: это стирает прогресс и таймер и может привести к повторным публикациям. Не убирайте из очереди незавершенный ролик, на который ссылается сохраненный прогресс.

Если нужно повторить публикацию **только на одной** площадке после ошибки, сделайте это вручную на этой площадке. Переключателей выбора платформ в текущем интерфейсе нет.

Возврат обработанного MP4 с TXT из `done` в `to_upload` создаст новый цикл на **всех трех** площадках, поэтому уже успешные публикации могут продублироваться.

## 10. Частые проблемы

| Проблема | Что сделать |
| --- | --- |
| `python` не найден или открывается Microsoft Store | Установите Python и заново откройте PowerShell. |
| `No module named ...` | Повторите установку библиотек из раздела 2. Запускайте программу именно через `.\.venv\Scripts\python.exe`. |
| Не найден `.venv\Scripts\python.exe` | Проверьте, что PowerShell открыт в папке AutoZaliver и выполнена команда создания `.venv`. |
| Ошибка `SyntaxError` после изменения CONFIG | Проверьте кавычки, запятые и скобки в измененных строках. |
| Не найден `client_secrets.json` | Скачайте Desktop OAuth JSON, правильно переименуйте и положите рядом с `autozaliver.py`. |
| YouTube сообщает об отказе в доступе | Проверьте выбранный Google-аккаунт, тестовых пользователей OAuth и включение YouTube Data API v3 в вашем проекте. |
| YouTube не завершил первичный вход | Выполните вход в отведенные 180 секунд; при необходимости увеличьте `oauth_timeout_seconds` в CONFIG и перезапустите приложение. Учтите правила повторных попыток из раздела 9. |
| Instagram сообщает о прокси | Проверьте IPv4, порт и данные прокси; исходная строка с `127.0.0.1` не является готовым подключением. |
| Instagram требует проверку или код | Проверьте аккаунт в обычном приложении и точный текст ошибки. Автоматический ввод таких подтверждений здесь не реализован. |
| TikTok не находит браузер, Node или npm | Повторите соответствующие шаги установки, затем заново откройте PowerShell. |
| Видео не появляется в очереди | Проверьте расширение `.mp4` и папку `to_upload`; вложенные папки не учитываются. |
| «Жду завершения записи» не исчезает | Файл еще меняется или имеет нулевой размер. Завершите экспорт видео. |
| Очередь есть, но загрузка не начинается | Проверьте статус: возможно, еще идет сохраненная двухчасовая пауза. |
| Файл в `done`, а публикации нет | Найдите ошибку нужной площадки в журнале. Автоматических повторов нет. |
| После «Стоп» окно сразу не закрывается | Дождитесь возврата управления от текущего загрузчика. Если принудительно завершить процесс, результат публикации может остаться неизвестным. |

Если ошибка остается, сохраните точный текст сообщения и название площадки. Пароли и содержимое файлов доступа для диагностики присылать не нужно.
