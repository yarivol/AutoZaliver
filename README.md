# AutoZaliver

Публикация готовых вертикальных MP4 в **YouTube, Instagram Reels и TikTok** через десктопное окно. Добавьте ролики в папку, выберите площадки и нажмите «Старт».

**Все настройки — только в `config.json`. Редактировать `autozaliver.py` для настройки не нужно.**

## Установка на Windows

### 1. Подготовьте компьютер

Понадобятся:

| Компонент | Для чего |
| --- | --- |
| Python 3.12 | Версия локального окружения, по которому составлен requirements.txt |
| Node.js с npm | Работа загрузчика TikTok |
| Git | Клонирование и обновления; при установке из ZIP можно обойтись без него |

Установщики: [Python](https://www.python.org/downloads/windows/), [Node.js](https://nodejs.org/), [Git](https://git-scm.com/downloads/win). В установщике Python включите `Add python.exe to PATH`, если такая опция предлагается. После установки заново откройте CMD.

**Все команды в инструкции предназначены для CMD.** Копируйте только содержимое блоков, без приглашения вроде `D:\AutoZaliver>`.

Проверьте установку:

```cmd
python --version
node --version
npm --version
```

### 2. Скачайте программу

Если папка программы уже есть, пропустите клонирование.

Для новой установки:

```cmd
cd /d D:\
git clone https://github.com/yarivol/AutoZaliver.git
```

Без Git: откройте репозиторий, нажмите **Code → Download ZIP** и распакуйте в `D:\AutoZaliver`. Файл `autozaliver.py` должен лежать непосредственно в этой папке.

Перейдите в папку программы. Если ваш путь другой, замените его:

```cmd
cd /d D:\AutoZaliver
```

### 3. Установите зависимости

Выполняйте команды по одной. Ждите полного завершения каждой команды; при ошибке сначала исправьте ее.

```cmd
if not exist .venv\Scripts\python.exe python -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install --timeout 300 -r requirements.txt
.venv\Scripts\python.exe -m pip install --timeout 300 --no-deps moviepy==2.2.1
.venv\Scripts\phantomwright_driver.exe install chromium
```

**Отдельная команда MoviePy обязательна для подготовки видео Instagram.** У используемых версий instagrapi и MoviePy конфликтуют ограничения на Pillow. Поэтому `requirements.txt` устанавливает `instagrapi[video]` и видеозависимости, а MoviePy устанавливается отдельно с `--no-deps`. Это обход конфликта зависимостей, а не гарантия обработки любого видео. Не заменяйте эту команду обычным `pip install moviepy`: он может изменить Pillow.

Node.js, npm и Chromium требуются самим [загрузчиком TikTok](https://github.com/haziq-exe/TikTokAutoUploader#pre-requisites).

Проверка основных импортов и запуска FFmpeg без публикации:

```cmd
.venv\Scripts\python.exe -c "import customtkinter, watchdog, googleapiclient, instagrapi, moviepy, imageio_ffmpeg; import subprocess; subprocess.run([imageio_ffmpeg.get_ffmpeg_exe(), '-version'], check=True); print('OK')"
```

Ожидаются сведения о FFmpeg и строка `OK`. Эта проверка не выполняет вход в аккаунты.

### 4. Создайте настройки

Команда не заменит уже существующий файл:

```cmd
if not exist config.json copy config.example.json config.json
notepad config.json
```

Заполните данные выбранных площадок по следующему разделу. Полный набор обязательных полей находится в [config.example.json](config.example.json). Сохраняйте все поля, даже если некоторые площадки отключены.

Правила JSON:

- двойные кавычки вокруг строк;
- `true` и `false` маленькими буквами;
- никаких комментариев `# ...` или `// ...`;
- никаких запятых после последнего поля;
- кодировка UTF-8, с BOM или без него;
- имя `config.json`, а не `config.json.txt`.

Проверка синтаксиса без вывода паролей:

```cmd
.venv\Scripts\python.exe -c "import json; from pathlib import Path; json.loads(Path('config.json').read_text(encoding='utf-8-sig')); print('JSON OK')"
```

### 5. Запустите

```cmd
start.bat
```

Можно дважды щелкнуть `start.bat` в Проводнике. Затем нажмите «Старт» в окне приложения.

**Сначала выполните установку из этой инструкции.** Текущий `start.bat` при отсутствии `.venv` использует старый список установки, в котором нет всех видеозависимостей. При существующем `.venv` он только запускает приложение и не исправляет недостающие пакеты.

## Настройка аккаунтов

### Выбор площадок

Замените значение `enabled_platforms` в `config.json`. Не добавляйте второй одноименный ключ.

| Режим | Значение поля |
| --- | --- |
| Только YouTube | `["YouTube"]` |
| Только Instagram | `["Instagram"]` |
| Только TikTok | `["TikTok"]` |
| Все площадки | `["YouTube", "Instagram", "TikTok"]` |

Например, для проверки Instagram:

```json
"enabled_platforms": ["Instagram"]
```

Это отдельное поле, не полный файл. Регистр названий важен. Порядок публикации всегда YouTube → Instagram → TikTok с пропуском отключенных площадок.

**Первую проверку проводите с одной площадкой и одним роликом.** Запуск действительно публикует видео: режима «проверка без публикации» нет.

### YouTube

1. Откройте [Google Cloud Console](https://console.cloud.google.com/), создайте или выберите проект.
2. Включите **YouTube Data API v3**.
3. Настройте экран согласия OAuth; при режиме Testing добавьте свой аккаунт в тестовые пользователи.
4. Создайте **OAuth client ID**, тип **Desktop app**.
5. Скачайте JSON и сохраните рядом с программой как `client_secrets.json`.

Для загрузок нужен OAuth, обычного API key недостаточно. Подготовка проекта описана в [инструкции Google](https://developers.google.com/youtube/v3/quickstart/python#step_1_set_up_your_project_and_credentials).

При первой загрузке откроется браузер. Войдите в аккаунт нужного канала и разрешите доступ. После успешного входа программа сохранит `token.json`. Время на первичный вход задается в `oauth_timeout_seconds`.

```json
"youtube_privacy": "public",
"youtube_made_for_kids": false
```

Видимость: `public` — публично, `unlisted` — по ссылке, `private` — лично. Признак «для детей» задается через `youtube_made_for_kids`. Эти поля действуют только на YouTube.

Непроверенные API-проекты могут ограничиваться личными загрузками даже при `public`. См. [ограничение Google](https://developers.google.com/youtube/v3/docs/videos/insert). Отдельного переключателя «сделать Shorts» в программе нет.

### Instagram

Заполните свои данные:

```json
"ig_username": "ваш_логин",
"ig_password": "ваш_пароль",
"ig_proxy": ""
```

Логин вводится без `@`. Пустой прокси означает прямое подключение.

При использовании прокси укажите строку провайдера в формате:

```text
http://ЛОГИН_ПРОКСИ:ПАРОЛЬ_ПРОКСИ@IPv4:ПОРТ
```

Код принимает HTTP-прокси с авторизацией и числовым IPv4. Данные прокси отличаются от логина и пароля Instagram. Если они содержат специальные символы, запросите у провайдера готовый URL с правильным кодированием.

**Двухфакторная проверка:** когда появляется поле «Код Instagram», получите код способом, настроенным в аккаунте, введите его и нажмите «Отправить код». На ввод отведено 180 секунд. После успешного входа сохраняется `session.json`.

Текущая версия поддерживает одну попытку ввода 2FA. При неверном коде или истечении времени этап завершается ошибкой. Поле не обрабатывает все возможные проверки личности Instagram. Кнопка «Стоп» во время ожидания кода может ждать завершения этого ожидания.

### TikTok

Укажите постоянное имя локального профиля:

```json
"tiktok_profile": "my_tiktok_account"
```

При первом обращении загрузчик предложит войти в браузере. Войдите в нужный аккаунт. Библиотека сохраняет cookies для последующих запусков; не меняйте имя профиля каждый раз.

В коде уже есть обход ошибки двух кнопок `Cancel` для Phantomwright и Playwright. Он исправляет конкретный локатор, а не все возможные изменения сайта TikTok.

После сообщения об успешном завершении функции проверьте наличие ролика в профиле.

## Видео и описание

**Название берется из имени MP4 без расширения.** Пробелы и подчеркивания остаются как есть.

Пример файлов:

```text
to_upload/
  Нашли пропажу.mp4
  Нашли пропажу.txt
```

Пример TXT в UTF-8:

```text
Первая строка игнорируется
Неожиданная находка в конце прогулки!
#приколы #видео
```

Результат:

- заголовок YouTube — `Нашли пропажу`;
- описание на всех площадках начинается с `Нашли пропажу`, затем добавляются строки TXT после первой;
- Instagram и TikTok получают название в подписи, отдельный заголовок им не передается.

Первая строка TXT пропускается для совместимости со старым форматом. Если TXT отсутствует или содержит одну строку, используется `default_description`.

Сначала положите TXT, затем готовый MP4. Программа видит только MP4 непосредственно в `to_upload`, без подпапок. Очередь сортируется по имени. Префиксы `001`, `002` помогут задать порядок, но тоже попадут в название публикации.

Программа не делает горизонтальное видео вертикальным и не проверяет все ограничения площадок. Добавляйте уже подготовленные ролики и не редактируйте их во время обработки.

## Ежедневный запуск

1. Добавьте готовые файлы в `to_upload`.
2. Откройте `start.bat`.
3. Нажмите «Старт» и при необходимости выполните вход.
4. Следите за журналом и проверьте публикации.

Файлы можно добавлять во время работы. Компьютер должен оставаться включенным, с интернетом, без перехода в сон. Не запускайте несколько окон одновременно: защиты от параллельной обработки одной очереди нет.

Изменение настроек: **«Стоп» → дождаться завершения → закрыть приложение → изменить config.json → запустить снова**. Настройки на лету не перечитываются.

## Очередь и повторная загрузка

Стандартный цикл: минимум 15 секунд проверки готовности файла → выбранные площадки с паузами по 20 секунд между этапами → перенос в `done` → 7200 секунд ожидания перед следующим роликом.

| Элемент | Значение |
| --- | --- |
| «Старт» | Запустить или продолжить очередь |
| «Стоп» | Прервать обычную паузу; текущий вызов загрузчика должен завершиться |
| «В очереди» | MP4 в папке, включая обрабатываемый до переноса |
| «Жду файлы» | Свободных файлов нет |
| «Жду завершения записи» | Проверяется, перестал ли файл изменяться |
| «Сон 2 часа» | Следующий ролик ожидает таймера |

**Даже если все выбранные площадки вернули ошибки, файлы переносятся в `done` и начинается пауза.** Папка `done` означает завершение попыток, а не успех публикаций. Для каждого цикла создается отдельная подпапка.

В `pipeline_state.json` сохраняются попытки и срок следующей загрузки. Перезапуск не сбрасывает паузу. Уже выполненные попытки, включая ошибочные, автоматически не повторяются. При аварийном завершении исход попытки может быть неизвестен — сначала проверьте аккаунт.

Чтобы повторить только одну неудавшуюся площадку:

1. Дождитесь завершения цикла и переноса в `done`, остановите и закройте приложение.
2. Оставьте в `enabled_platforms` только нужную площадку.
3. Скопируйте MP4 и TXT из подпапки `done` обратно в `to_upload`.
4. Запустите приложение. Сохраненная пауза продолжает действовать.

Не удаляйте файл состояния для обхода ожидания. Если вернуть ролик при включенных всех площадках, успешные публикации могут продублироваться.

## Справочник настроек

Полный шаблон — [config.example.json](config.example.json). Все его поля обязательны.

| Поля | Назначение |
| --- | --- |
| `to_upload`, `done` | Папки очереди и архива |
| `state_file` | Прогресс и сохраненный таймер |
| `enabled_platforms` | Включенные площадки |
| `youtube_client_secrets`, `youtube_token` | OAuth-файлы YouTube |
| `youtube_privacy`, `youtube_made_for_kids` | Видимость и признак «для детей» |
| `ig_username`, `ig_password`, `ig_proxy`, `ig_session` | Данные Instagram, прокси и файл сессии |
| `tiktok_profile` | Имя локального профиля TikTok |
| `default_description` | Описание при отсутствии подходящего TXT |
| `default_title` | Поле совместимости; текущий заголовок берется из MP4 |
| `file_ready_seconds` | Интервал проверки готовности файла |
| `platform_pause_seconds` | Пауза между этапами |
| `cycle_pause_seconds` | Пауза после ролика, стандартно 7200 |
| `oauth_timeout_seconds` | Ожидание первичного входа Google |
| `network_timeout_seconds` | Поле совместимости; текущий код не применяет его как общий сетевой таймаут |

Относительные пути отсчитываются от папки приложения. Абсолютный Windows-путь можно записать как `D:/Videos/to_upload`.

В текущем GUI надписи «20 секунд» и «2 часа» фиксированы. При изменении интервалов фактическое ожидание меняется, но эти надписи могут остаться прежними. Ожидание 2FA фиксировано на 180 секундах и не связано с `oauth_timeout_seconds`.

## Решение проблем

| Ошибка | Что проверить |
| --- | --- |
| `No module named ...` | Повторите установку через `.venv\Scripts\python.exe`; для MoviePy используйте отдельную команду с `--no-deps` |
| Нет config.json / отсутствуют ключи | Добавьте недостающие поля из полного шаблона, сохранив свои данные |
| `JSONDecodeError` | Кавычки, запятые, отсутствие комментариев и Python-значений True/False |
| `Unexpected UTF-8 BOM` | Актуальный код читает utf-8-sig; проверьте, что запускаете нужную копию программы |
| Нечитаемые русские буквы | Восстановите UTF-8 исходник из исправной копии; не перекодируйте весь файл через ANSI |
| `TwoFactorRequired` | Введите код в GUI; повторный запрос после неправильного кода не реализован |
| `Could not generate video thumbnail` | Проверьте MoviePy, FFmpeg и воспроизведение самого MP4 |
| `DNSError` / `private transport failed` | Сеть, VPN/прокси, адрес из ошибки; это не доказывает неверный пароль |
| YouTube `uploadLimitExceeded` | Проверьте лимит загрузок аккаунта; переустановка Python его не снимает |
| YouTube `RedirectMissingLocation` | Сохраните журнал и версии пакетов; замена транспорта не гарантирует исправление любой сетевой ошибки |
| TikTok `strict mode violation` | Для Cancel обход уже есть; для другого локатора нужен новый текст ошибки |
| Очередь есть, загрузки нет | Сохраненная пауза и выбранные площадки |

Проверка видеозависимостей:

```cmd
.venv\Scripts\python.exe -c "import moviepy, imageio_ffmpeg; print(moviepy.__version__); print(imageio_ffmpeg.get_ffmpeg_exe())"
```

Проверка сети — адреса копируются **без квадратных и круглых скобок**:

```cmd
nslookup www.instagram.com
curl.exe -4 -I https://www.instagram.com
```

Это проверка веб-адреса, а не всех серверов Instagram API. Работа сайта в браузере не гарантирует работу загрузчика.

Журнал показывается в окне и автоматически в файл не сохраняется. Скопируйте нужные строки до закрытия. Для диагностики передавайте текст ошибки без паролей, токенов и кодов 2FA.
